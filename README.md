# MyoAssist Lumbar Flexion Model

Completed implementation of a 28-muscle model combining the original 22 leg
muscles with six lumbar muscles for sagittal flexion and extension.

The integrated model is located at
`models/22muscle_2D_lumbar/myoLeg28_2D_LUMBAR.xml`.

This project is complete and no further development is planned.
